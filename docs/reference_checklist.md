# Lesson Preparation and Completion Checklist

## Prepare (every lesson)
- [ ] Venv activated, `check` passes, server runs.
- [ ] Starting checkpoint matches chapter snapshot.
- [ ] Admin/shell commands copied, demo rows exist.
- [ ] Timings + exit ticket ready.

## Complete (every lesson)
- [ ] Ending checkpoint code matches repo state.
- [ ] Exercises have attempts; exit tickets collected.
- [ ] New terms used correctly by at least two learners.
- [ ] Troubleshooting entries hit are noted for next cohort.

## Full-project drill (Ch8)
- [ ] Fresh DB `migrate` works.
- [ ] List/search/empty, detail/404, layout/CSS, admin filter/search.
- [ ] Form create/update/errors/redirect, POST-only delete.
- [ ] Signup/login/POST-logout, protected writes with `next`, auth-aware nav.

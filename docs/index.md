## What you will learn
In this course, you will learn to develop applications with [Django](https://docs.djangoproject.com), a web-framework written in Python. 

## Why Django?

- **Easy and fast:** You can ship an idea without relying on any extra functionality.

- **Fully loaded:** You can handle almost all common web development tasks including authentication, content management etc.

- **Secure:** Django provides many security features in addition to its strong authentication framework.

- **Versatile:** It has been used to build all sorts of applications with all sorts of scale.
